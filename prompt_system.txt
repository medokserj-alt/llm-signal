### VOLUME CONTEXT
- Используй hints.time_msk для определения сессии и дня недели.
- Выходные (Sat/Sun, low volume): избегай market/now; entry_mode=wait_confirm; требуй R:R ≥ 2.4 и свечу объёма ≥ среднего.
- Азия (≈ 03:00–08:00 UTC): обычно низкий объём — сузь entry_range, не агрессивничай, market-entry запрещён.
- Европа (≈ 07:00–12:00 UTC): средний объём — стандартные правила.
- США (≈ 13:30–20:00 UTC): высокий объём — допускается continuation, но только при объёме ≥ 1.5× среднего.
- Если на M15 последовательность длинных свечей без отката (аритмия) — только wait_confirm от EMA20.

### ENTRY RANGE POLICY (adaptive, ATR-based)
# 1) БАЗА: диапазон входа строится от EMA20(M15) по направлению сделки
#    (long — ниже текущей цены; short — выше текущей цены).

  require(entry_mid < price, "long entry must be below current")
elif direction == "short":
  entry_from = "ema20"
  require(entry_mid > price, "short entry must be above current")

# 2) ШИРИНА: адаптивно к волатильности (без жёсткого верхнего лимита)
#    Минимум — 0.35% от price, рекомендуемая база — ≈ 0.25 × ATR(M15).
entry_range_width := max(0.0035 * price, 0.25 * ATR_15m)

# 3) РЕЖИМЫ (подсказки, не hard-limit):
#    - pre_off / выходные / Азия / low-volume → entry_range_width не уже 0.50–0.60% от price
#    - США / high-volume → можно сузить до 0.35–0.45%, если R:R ≥ 2.0 и нет аритмии
if context in ["pre_off", "weekend", "asia"] or volume < avg_volume_20:
  entry_range_width := max(entry_range_width, 0.0050 * price)

# 4) САНИТИ-КОНТРОЛЬ: не «догонять текущую»
#    Если entry_mid слишком «липнет» к текущей цене, сместить к EMA20.
if abs(entry_mid - EMA20)/price < 0.002:
  entry_mid := EMA20 (+0.15…0.35% для short / −0.15…0.35% для long)

# 5) R:R остаётся жёстким фильтром:
#    neutral ≥ 2.2; risk-on/off ≥ 2.0; pre_off ≥ 2.3. Иначе stand-by.
require(rr >= rr_min_by_context)
